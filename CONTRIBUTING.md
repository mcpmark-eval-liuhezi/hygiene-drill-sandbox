# Contributing

Thanks for wanting to help improve this repository! Here is how to propose changes:

- **Fork or branch first** — never commit directly to `main`; create a short-lived, descriptively named branch for your work.
- **Keep changes small and focused** — one logical change per pull request makes review much easier and faster.
- **Write a clear PR description** — explain *what* changed and *why*, and link any related issues.
- **Keep the docs tidy** — update or delete stale files rather than leaving deprecated clutter behind.
- **Be responsive and kind** — expect feedback, engage with reviewers, and remember this is a learning sandbox for everyone.
